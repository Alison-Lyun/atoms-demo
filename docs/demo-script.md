# 2–3 分钟演示脚本

在线入口：https://atoms-demo-indol.vercel.app  
公开源码：https://github.com/Alison-Lyun/atoms-demo

首次打开是独立的匿名会话，需要在当前浏览器创建项目。演示前先完成一次生成和两次修改，保留三个成功版本；不要清理该浏览器的 cookie。模型等待时间不计入精简演示，可通过剪辑压缩并注明等待，现场演示则保留真实等待。

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:20 | 打开工作台，展示项目需求、生成过程和成功预览 | 自然语言经真实模型生成可执行 HTML；不是固定模板 |
| 0:20–0:50 | 计算 `2+3`，再试 `1÷0`，展示历史 | 有效结果保存，非法输入显示错误且不写历史 |
| 0:50–1:15 | 展示第一次追改“清空历史”，点击清空后计算 `7×6` | 同一项目继续改动；数据只有在用户点击时清空 |
| 1:15–1:45 | 展示第二次追改“再次使用 + Enter”，复用 `42`，按 Enter 计算 `42+1` | 连续两次修改仍保留原功能和数据 |
| 1:45–2:05 | 刷新页面，查看 `42`、`43` 历史 | 真实 Supabase 持久化，不只是页面变量 |
| 2:05–2:30 | 在版本面板恢复早期代码，再查看预览和历史 | 恢复会创建新版本，沿用当前业务数据；不声称回到过去的数据 |
| 2:30–2:50 | 查看源码/导出入口，简述待办与计时器的验收结果 | 生成产物可检查；源码、架构和测试记录可供复核 |

## 可直接输入的演示需求

首次生成：

> 做一个四则运算计算器，支持两个数字和运算符，计算历史持久化保存，刷新仍在。空输入、无效数字、除零要显示中文错误，不能把无效结果写入历史。

第一次修改：

> 在当前计算器增加“清空历史”按钮。只在点击时清空，加载和更新版本时保留历史，保持原有计算与错误处理。

第二次修改：

> 为每条历史增加“再次使用”按钮，把结果填回第一个输入框；支持输入框按 Enter 计算。保留历史数据和清空历史功能。

以上是人工演示提示词，重新生成的界面可能不同。自动化验收使用的精确提示词和断言位于 `tests/production-model.spec.ts`，已执行结果见 [验收记录](acceptance.md)。

## 结束时说明

当前版本生成自包含单页应用；支持生成、连续修改、持久化、源码查看与代码恢复。匿名会话清理 cookie 后无法找回，iframe 没有进程级资源限制，启动验证也不能替代业务功能验收。录屏不能替代公开可访问的 Demo 与仓库。
